# Security

Readdown renders untrusted Markdown and HTML inside a WebKit view, so rendering safety is part of the product.

If you find a way to execute script, reach the network, or read files through a crafted document, please report it privately to hello@readdown.app rather than opening a public issue. Include the document that triggers it. You will get a reply within a few days, and a fix ships through the normal auto-update channel.

Only the latest release receives fixes; Readdown updates itself, so most users are on it within days.
